# Roadmap

## Completed MVP

- Static React dashboard with landing, overview, trace explorer, trace detail and analytics.
- FastAPI/Postgres trace ingestion, metrics and demo seed endpoints.
- Explicit local demo fallback when the API is unavailable.
- TypeScript telemetry SDK and executable demo agent.
- GitHub Pages workflow and deployment docs for Render/Koyeb + Neon/Supabase.

## Future improvements

- Auth, team scopes and environment separation.
- Migration tooling instead of startup table creation.
- Alerts and anomaly detection for latency/cost/error spikes.
- Real provider integrations and automatic instrumentation wrappers.
- Sampling controls, retention policies and export APIs.
- Hosted SDK packaging with versioned releases.
