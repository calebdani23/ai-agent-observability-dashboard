# Screenshot Capture Guide

Real screenshots are not committed from this environment. Capture these after running the stack locally or against deployed services:

1. Landing page (`/`): hero and product cards.
2. Dashboard (`/dashboard`): metric cards and charts with live or demo data banner.
3. Trace explorer (`/traces`): table with filters and status badges.
4. Trace detail (`/traces/:id`): summary, timeline, prompt inspector and tool calls.
5. Analytics (`/analytics`): cost, token, error and tool-usage views.

Recommended size: 1440×1000 for README crops. Avoid exposing real prompts, secrets or user data.
